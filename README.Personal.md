# HappyShop

A Java desktop shopping application built using JavaFX.

## Features
- Browse and search products
- Manage a shopping trolley
- Simulated cash and card checkout
- View receipts and order status updates

## Technologies
Java, JavaFX, Maven and JUnit.

## About
This university project helped me develop my object-oriented programming, GUI design and testing skills. Payments are simulated, not real.
